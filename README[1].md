# Ritik Choudhary — GenAI Student Portfolio

A polished, responsive portfolio for a first-year B.Tech student exploring Generative AI.

## Personalize before publishing
- Replace `your-email@example.com` with your actual email.
- Replace the GitHub and LinkedIn URLs with your profiles.
- Add your college, branch, certificates, real project links, and profile photo if desired.
- Replace placeholder projects with your actual work as you build it.

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `ritik-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch → `main` → `/ (root)` → Save.
5. Open the generated URL in an incognito window to verify it is publicly accessible.
6. Submit that live URL to your mentor.

## Publish with Vercel
Import the GitHub repository into Vercel and deploy. The resulting `vercel.app` URL can be submitted after testing it.

No build step is required.
